## 🎉 Lepro Cloud v0.2.2

This release adds an optional regional-server override and improves connection troubleshooting, account routing and diagnostic privacy.

### Highlights

- 🌍 Adds an optional server-region selection to email/password setup, Configure and reauthentication. Automatic detection remains the default, and you can return to it at any time.
- 🔎 Reports where setup failed, which region was contacted, Lepro's error code and the HTTP status when available.
- 🔄 Corrects app authorization and session renewal so a server migration keeps the final validated region.
- 🔒 Prevents automatic HTTP redirects from forwarding authenticated requests outside the validated regional-routing flow.
- 📡 Improves MQTT connection, subscription, command and state-report diagnostics, including numeric rejection codes and clearer retry and cleanup failures.
- 🛡️ Removes device identifiers, arbitrary exception text and sensitive metadata from integration logs and downloaded diagnostics.
- 🧰 Adds active-versus-configured region details, product-classification information and report-validation counters to downloaded diagnostics.

Requires Home Assistant 2026.4.0 or newer. Existing accounts do not need to be configured again.
