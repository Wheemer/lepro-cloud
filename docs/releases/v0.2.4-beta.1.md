## 🧪 Lepro Cloud v0.2.4-beta.1

This prerelease adds support for favourites saved to a Lepro group.

### Highlights

- 🎨 Shows group favourites in the Effect selector for compatible lights in that group. Choose the effect on the light you want to control.
- 🔎 Adds a debug count for favourites returned by Lepro for each home, to help investigate an empty Effect selector.

If your favourites appear in the Lepro app but are missing in Home Assistant, try this prerelease and let us know whether they appear and play. See [issue #53](https://github.com/Wheemer/lepro-cloud/issues/53).

Requires Home Assistant 2026.4.0 or newer.
