## 🧪 Lepro Cloud v0.2.4-3

This prerelease improves how Lepro Cloud loads saved favourites and checks whether an unavailable light has come back online.

### Highlights

- 🎨 Tries the home the Lepro app selects for individual favourites when the device’s discovery homes return none.
- 📋 Keeps favourites from pages that loaded before a timeout, skips malformed records, and removes group favourites when the light is no longer in the group.
- 💡 Plays saved colours with separate brightness values and brightness-only favourites without a pattern payload.
- 📡 Uses the Lepro app’s read-only reachability check for unavailable lights. Logs distinguish a missing command acknowledgement from a failed command.
- 🔒 Keeps the MQTT session secret out of callback thread names and logs safe counts for loaded and playable favourites.
- 🛠️ Updates Ruff, Hassfest, Scorecard, and CodeQL’s SARIF upload action.

Requires Home Assistant 2026.4.0 or newer.
