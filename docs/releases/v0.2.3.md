## 🎉 Lepro Cloud v0.2.3

This update improves favourite effects, shared-device discovery, and how quickly Home Assistant reflects changes to your devices.

### Highlights

- 🎨 Saved favourites now use their own brightness settings, and dimming a brightness-only favourite keeps it active.
- 💡 Built-in bulb effects report their state more reliably. Supported E1 lights retain their colour controls when Lepro sends incomplete device information.
- 👥 Devices from accessible families can still load when another family fails to respond.
- 📡 Home Assistant refreshes device state after a command is acknowledged and ignores reports from an old MQTT connection.
- 🔐 Removes the experimental **Sign in through the Lepro app** option from new setups. Existing app-linked sessions can still renew.
- 📝 The README now walks through creating a second Lepro account, sharing your devices, and using that account in Home Assistant.

Requires Home Assistant 2026.4.0 or newer.
