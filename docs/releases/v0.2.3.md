## 🎉 Lepro Cloud v0.2.3

This release improves saved effects, shared-device discovery, and MQTT state recovery. Setup now uses your Lepro email address and password.

### Highlights

- 🎨 Uses each favourite’s saved brightness and keeps brightness-only favourites selected when you dim them.
- 💡 Improves built-in bulb effect readback and recovers the controls for verified E1 models when device type information is missing or malformed.
- 👥 Keeps devices from accessible families available when another family fails to load and preserves existing device registrations during incomplete discovery.
- 📡 Ignores MQTT reports from a replaced connection and requests updated device state when a command is acknowledged.
- 🔐 Removes the Lepro app sign-in option from new setup. Existing app-linked sessions can still renew or switch to email credentials through **Configure**.
- 📝 Adds step-by-step instructions for using a separate Lepro account in Home Assistant, including how to share devices and accept the invitation.

Requires Home Assistant 2026.4.0 or newer. Existing email and password setups continue to work.
