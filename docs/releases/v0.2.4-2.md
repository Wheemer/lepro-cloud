## 🧪 Lepro Cloud v0.2.4-2

This prerelease keeps saved favourites available when loading a later page fails.

### Highlights

- 🎨 Keeps favourites from successful pages when Lepro fails to return a later page. This includes favourites saved directly to S1-30 and S1-5 strips.
- 👥 Includes group favourites support from v0.2.4-1. Compatible lights in a Lepro group can show its favourites in the Effect selector.

Requires Home Assistant 2026.4.0 or newer.
